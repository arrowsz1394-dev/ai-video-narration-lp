# AI動画ナレーションメーカー｜LP検証版

副業06「資料制作」から、AIを活用したLP／簡易Webサイト制作へ展開できるか検証するためのポートフォリオです。

## GitHub Pages 公開手順
1. 公開リポジトリを作成
2. `index.html` と `.nojekyll` をリポジトリ直下へ配置
3. GitHubの **Settings → Pages** を開く
4. **Build and deployment → Source** で **Deploy from a branch** を選択
5. Branchを `main`、Folderを `/(root)` にして保存
6. 発行されたPages URLでPC・スマホ表示を確認

## 注意
- GitHub Pagesは静的ホスティングのため、このデモ版フォームは実送信しません。
- 実案件で問い合わせ受信まで行う場合は、同梱済みのNetlify版など、フォーム処理に対応したホスティングを使用します。
- 本LPは架空サービスのポートフォリオです。
